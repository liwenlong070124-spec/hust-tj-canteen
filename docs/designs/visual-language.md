# 同济食光视觉语言

> Created: 2026-10-04
> Updated: 2026-10-04
> Status: accepted

## 问题陈述

食堂信息天然碎片化，用户常常在“现在吃什么、去哪吃、要走多远”之间来回切换。设计需要让信息快速可读，同时保留校园生活的温度，而不是做成冷冰冰的目录。

## 最终决策

- **色彩**：奶油底色承载内容，浅橙负责食欲与操作，墨绿负责阅读与导航，浆果色强调价格/结果。
- **形状**：圆角卡片对应餐盘与便当盒；小胶囊用于筛选、标签和营业状态。
- **字体**：系统无衬线保证中文阅读；首页品牌标题保留手帐气质，手机页面标题 22–28px、卡片标题 14px、正文 14px。
- **动效**：由 App Router `template.tsx` 统一承载 420ms 缓动滑入；抽签页保留翻牌和轨道旋转，系统减少动效时关闭动画。无需大体积动画库。
- **响应式**：桌面使用左侧导航与三列卡片，移动端使用底部三项导航，菜品与快捷入口均为双列。

## 复用规则

所有页面都在 `AppShell` 内渲染；按钮、标签、食物卡片和 section heading 共享全局 token。新增组件先在 `/playground/` 展示，再进入产品页面。
