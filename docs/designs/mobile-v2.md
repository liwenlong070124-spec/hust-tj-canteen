# v0.2 移动端改版

> 2026-10-04 · 同济食光 v0.2.0

## 布局与交互

- 手机端菜品和金刚区均为双列，删除重复的推荐列表；桌面菜品三列、快捷入口四列。
- 首页将拉面图形并入浅橙背景板，文字、随机入口与搜索按钮在同一视觉层级；搜索展开后自动聚焦。
- 新增 `/foods/<slug>/`：对应图片、参考价、菜品描述、窗口关联、食堂入口、资料声明与收藏。手机操作条位于导航上方，留出安全区。
- 新增 `/saved/` 收藏列表；与图鉴、详情和个人页共用 `useSavedFoods`，保留旧浏览器收藏。
- 我的页面采用居中头像与昵称，22px 手机标题，实际收藏数和关键词数；无真实登录。
- 路由由 `template.tsx` 统一使用 420ms 的 `cubic-bezier(.16,1,.3,1)` 缓动滑入。减少动效时关闭动画，抽签等待也取消。

## 信息与素材边界

食堂目录补齐公开采购公告中的六个名称；历史食堂/旧称另列，不把同德园和历史清真称呼重复计数。目录是索引，不是坐标地图。未核实的位置和营业时间明确待补充。

11 张图片逐菜生成、检查并压缩为本地 WebP，合计约 1.3MB，每张小于 250KB。菜品卡片、详情和抽签均显示 AI 示意说明，食堂建筑使用代码原生 SVG 示意。窗口、菜单和价格是编辑参考，不能用于证明真实供应或清真认证。

## 可维护性

`globals.css` 保留基础 token 与原有组件样式，`redesign.css` 集中管理 v0.2 响应式升级；不引入动画依赖。业务位于 `features/`，路由只组合组件。独立的静态预览不改变进程工作目录，因此构建替换 `out/` 后仍能继续服务。

新增内容遵循 [注册表 SOP](../specs/data-registry.md) 和 [素材 SOP](../design/food-assets-v2.md)。真实食堂照片应有使用权限，并同步修改图示说明。

## 验收范围

- 320px、390px 手机视口及 1280px 桌面视口：布局、双列、字号、导航与详情操作。
- 搜索、筛选、收藏取消/恢复、个人页计数、收藏列表刷新、抽签跳转。
- lint、TypeScript、静态构建、产物约束和自动回归测试。
- 真机 Safari、硬件安全区、弱网尚需后续真机验收，不能以模拟视口替代。
